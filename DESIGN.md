# 代码工作台

Top layout: the supplied Tellyn logo sits outside the search field on its left. Search is the first row, with a magnifier inside the field and icon-only pin/refresh actions with accessible labels. A horizontal project tab bar follows, with a persistent plus button at its right. Adding a project creates and selects its tab; only the selected project's panel is visible. Arrow keys, Home and End navigate tabs. Project headings are 23px. Expanded content follows the supplied application-list references: pale gray canvas, white rounded branch cards, quiet leading icon tiles, pill navigation, generous spacing and strictly neutral grayscale values; no tinted accents, decorative header copy or large overview block.
Chinese local Git evidence dock. It starts as a 78px strip attached to the right edge of the monitor work area and stays visible across macOS workspaces. Hover or click expands it leftward to 460px; leaving collapses it unless the user chooses 固定展开. Native width and position animate together over 240ms with an ease-out curve and a fixed right edge. Content fades and slides gently without reflow; reduced-motion preference disables both animations. Collapsed content remains mounted but inert. The strip shows risk worktrees, branches with current coding evidence, and branches merged into the configured local base. macOS-like grayscale palette: light background #f7f7f7, surface #ffffff, ink #1d1d1d, secondary #707070, line #e5e5e5; dark mode uses #1c1c1c and #282828 surfaces. No decorative accent color. System Chinese sans for content; system monospace for paths, SHAs and evidence captions. CSS tokens live in src/styles.css.

Expanded view groups local branches under each project and defaults to all local branches, including the base and merged branches, ordered strictly by latest commit time descending. Unknown commit times sort last; ties use branch name. The user can hide unchecked or merged branches explicitly. Each branch shows its latest commit, coding evidence, local merge evidence and exact running SHA deployment evidence. The worktree evidence card remains behind a native details control. Unknown and failed evidence never becomes success; missing or mismatched deployment evidence remains explicit. GitHub PR/CI evidence loads per worktree; Tellyn deployment evidence loads for six environment × service pairs when the panel expands. Search/filter state is transient. Branch ancestry and feature relationship lines remain exploratory: Git cannot reliably reconstruct a branch's original parent after rebases, cherry-picks or squash merges, so the UI must not invent a parent.
