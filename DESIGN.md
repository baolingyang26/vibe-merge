# 代码工作台
Chinese local Git evidence panel, optimized for a 460px Mac side window. Calm blue steel instrument palette: background #edf1f4, paper #ffffff, ink #253644, muted #536c7c, accent #245e80, warning #74470a. System Chinese sans for content; system monospace for paths, SHAs and evidence captions. CSS tokens live in src/styles.css.

Signature: each worktree is an evidence strip with a blue left edge and parallel status dimensions. No overall completed indicator. Native details exposes evidence without adding screens. Native text fields and buttons own all actions; no modal required for removing a reversible local registry entry. Search/filter state is transient because this is a private desktop window. Unknown and failed evidence never becomes success. GitHub evidence loads explicitly per worktree; deployment evidence loads explicitly for six environment × service pairs. Only verified evidence is labeled deployed; missing and mismatched evidence remains explicit. All failures remain inline, busy actions disable duplicate submits, search clears with restored focus.
