# 代码工作台
Chinese local Git evidence panel, optimized for a 460px Mac side window. macOS-like grayscale palette: light background #f5f5f7, surface #ffffff, ink #1d1d1f, secondary #6e6e73, line #e5e5e8; dark mode uses #1c1c1e and #2c2c2e surfaces. No decorative accent color. System Chinese sans for content; system monospace for paths, SHAs and evidence captions. CSS tokens live in src/styles.css.

Signature: each worktree is a quiet white evidence card with parallel status dimensions and a subtle divider. No overall completed indicator. Native details exposes evidence without adding screens. Native text fields and buttons own all actions; no modal required for removing a reversible local registry entry. Search/filter state is transient because this is a private desktop window. Unknown and failed evidence never becomes success. GitHub evidence loads explicitly per worktree; deployment evidence loads explicitly for six environment × service pairs. Only verified evidence is labeled deployed; missing and mismatched evidence remains explicit. All failures remain inline, busy actions disable duplicate submits, search clears with restored focus.
